Privacy

  • No storage of User-Agents with IPs. This applies to every tier, Pro included. UAParse parses the string in memory and returns the result. It does not write User-Agent strings to any database, log or analytics tool, and never stores them next to an IP address.
  • Short-lived rate-limit counters. To enforce the free per-minute limit, Cloudflare's rate-limiting feature keeps a counter keyed by your IP address for about 60 seconds. It holds a number, not your User-Agent.
  • In-memory result cache. Parse results are cached in the Worker's memory, keyed by a SHA-256 hash of the User-Agent, so repeat lookups are fast. The cache holds no IP or API key, is never written to disk or storage, and disappears when the Worker instance is recycled.
  • API keys. Only a SHA-256 hash of each key is stored (Cloudflare Workers KV). Usage counters per key per UTC day are kept in a Cloudflare Durable Object for about two days. They contain counts only.
  • RapidAPI (only for calls to /rapidapi/v1/*). If you use UAParse through the RapidAPI marketplace, RapidAPI is a processor for those calls: it handles your account, API key, subscription, billing and usage counting, and forwards each request to UAParse under its own privacy policy. UAParse receives the User-Agent strings you send plus RapidAPI's username and plan headers; it uses a one-way hash of the username only for per-minute rate limiting and stores nothing else. Direct calls to /v1 and /mcp do not involve RapidAPI.
  • UAParse Pro payments. Pro subscriptions are sold and billed by Polar (merchant of record), which processes your payment and email address under its own privacy policy. UAParse never receives card details.
  • Pro license keys. Polar issues the license key. Polar notifies a small companion service run by the UAParse operator, which stores the key with its status, plan, expiry and Polar's customer and subscription IDs (no name, email or payment data) in Cloudflare Workers KV so UAParse can check it. UAParse only reads that record; it never logs the key, and its usage counter uses a one-way hash of the key. Revoked or expired keys stop working.
  • Daily unique visitor count. To count unique visitors per day, UAParse keeps a salted, daily-rotating hash of your network address (IPv6 grouped by /64) in Cloudflare Workers KV for up to 9 days. It is counted only on the homepage, the API (/v1/*) and POST /mcp, not on RapidAPI calls. Your IP address itself is not stored, and the hash is never stored with a User-Agent.
  • No logs, cookies or third-party analytics. Cloudflare Workers Logs are turned off for this service, there are no cookies, and the page loads no third-party scripts.
  • Infrastructure. UAParse runs on Cloudflare Workers. Cloudflare processes requests as our infrastructure provider.
